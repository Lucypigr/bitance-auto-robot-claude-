# 幣安回測平台

純瀏覽器（HTML／CSS／JavaScript）的 **Binance 現貨／USDT 永續合約歷史回測工具**，介面為繁體中文，主打「非專業投資者也能用」。
無後端、無需註冊，資料直接從 Binance 公開 API 下載，所有運算在你的瀏覽器（Web Worker）內完成。

## 功能

- **儲存／匯出／並排比較**：結果頁可「💾 儲存這次回測」（存在瀏覽器），並匯出交易明細 CSV、淨值曲線 CSV、完整報告 JSON、候選排行榜 CSV（走動式驗證也可匯出各折與串接淨值）。頂端「📁 我的回測」可載入設定、改名、刪除、匯入／匯出 JSON，並勾選 2～4 筆**並排比較**績效與疊圖淨值曲線；設定不同時會提示不能直接比。
- **新手篇**：頂端「🔰 新手篇」開啟 7 頁圖文教學（回測是什麼、第一次操作、設定怎麼選、自動搜尋或手動、怎麼看結果、常見陷阱、進階工具），可一鍵示範。
- **各幣種損益**：結果頁列出每個幣種在訓練期與樣本外的淨損益、報酬率、交易數、勝率，合計等於投組總成績。
- **指標示意圖**：每個條件與 K 線型態的 ⓘ 說明、手動策略的條件列、自動搜尋的指標池，都附有「長什麼樣子」的示意圖（內嵌 SVG，隨深淺色與漲跌顏色設定變化）。
- **設定檢查**：交易數偏少時自動展開，逐層列出「單一條件 → 同時成立 → 進場訊號 → 實際成交」的次數並給出具體建議（也檢查停利是否小於成本、USDT 換算、沒設出場等）。
- **選幣**：幣種清單可依 24h 成交額、**24h 漲幅榜**、跌幅榜、**歷史漲幅榜（幾天前的某段區間，用日線計算）**排序，並可一鍵選取榜單前 N 名（注意：這是當下榜單，回測過去有事後挑贏家的偏差；不是歷史漲幅榜策略回測）。
- **台股（日線）**：上市櫃股票與 ETF 的日 K 回測（資料：FinMind 公開 API 與證交所行情表，皆可由瀏覽器直接呼叫）。用除權息／分割／減資事件計算「還原股價」，時間軸是真實交易日曆；只做多、整股成交、買賣手續費（含最低手續費）＋賣出證交稅（股票 0.3%／ETF 0.1%），開盤漲停鎖死視為買不到；Sharpe 以 252 個交易日年化。
- **市場**：Binance 現貨、USDT 永續（含歷史資金費率與標記價格）；可搜尋全部 USDT 交易對，最多同時回測 15 個。
- **週期**：5m／15m／1h／4h／1d；只使用已收盤 K 線。
- **回測模型**：做多／做空、手續費、不利方向滑價、停損／停利／移動停損、1～10× 槓桿、資金費率、維持保證金、逐倉估計清算、資金平均分配、完整淨值曲線與逐筆交易。
- **指標**：RSI、EMA50/200、MACD、布林、ADX/DI、ATR、KD、Supertrend、Keltner、VWAP、OBV、CCI、MFI、Donchian、成交量。
- **K 線型態**：槌頭、倒槌頭、上吊線、流星線、看漲／看跌吞噬、十字星、晨星、暮星。
- **跨週期 AND 條件**：例如 `4h RSI 超買 AND 1h MACD 死叉 AND 15m 流星線`。高週期訊號必須等該根 K 線真正收盤才生效，最快下一根開盤成交。
- **指標參數可調**：每個條件的所有參數（RSI／ADX／ATR／KD／CCI／MFI 週期與門檻、EMA 快慢線、MACD 快／慢／訊號線、布林天數與標準差倍數、Supertrend、Keltner、OBV、成交量…）都能直接輸入數字（有合理範圍檢查，例如快線必須小於慢線）。自動搜尋可勾選「同時搜尋指標參數」，每個指標再試 3～4 組常用參數，候選數上限不變；預設關閉（參數固定），因為可挑的組合越多越容易過度擬合。
- **條件邏輯（OR／NOT）**：每個進場條件可勾「非」（NOT），並指定群組 A～D：同群組＝「或」，不同群組＝「且」，例如 `(RSI 超賣 或 看漲吞噬) 且 4h EMA 多頭`。出場條件仍是任一成立即出場。
- **部位規則**：預設各幣種獨立資金（sleeve）；可改為「共用資金池 + 同時最多持倉 N 檔」（每檔資金＝已實現淨值 ÷ N，滿檔時新訊號略過）；停損可搭配「每筆風險 % 本金」定位（倉位＝風險金額 ÷ 停損距離，受槓桿與資金上限限制）。
- **參數敏感度**（結果頁分頁）：以策略的停損／停利為中心，掃 0.5～2× 的格子（訓練期與樣本外各一張熱度圖）與槓桿／各條件參數，看績效是「一片平坦」還是「只有一個尖峰」（尖峰＝過度擬合警訊）。樣本外的格子僅供檢視，不應拿來再調參。
- **走動式驗證 Walk-forward**：把資料切成多折，每折只用「當折之前的訓練期」重新搜尋並挑冠軍，再把策略套在緊接著、從未看過的測試期，各折淨值串接。某折若無合格冠軍就空手。報告串接報酬、買入持有、獲利折數與走動效率。
- **停損停利單位**：可用價格 % 或 USDT 損益金額（例如投入 6U、停利 +2U、停損 −3U），手動與自動搜尋皆支援。
- **自訂指標池**：自動搜尋預設包含 RSI、EMA/MACD 交叉、布林與全部 9 種 K 線型態；可在「自訂搜尋的指標池」另外勾選 ADX、KD、Supertrend、Keltner、VWAP、OBV、CCI、MFI、Donchian、成交量等全部條件。
- **自動搜尋**：多／空、2～4 個 AND 條件、RSI 70/75/80 與 30/25/20、EMA／MACD 交叉、布林上下軌、反轉型態、停損 1/2/3/5%、停利 1/2/3/5/10%、槓桿 1/2/3/5/10×；候選上限 30/60/120/180/300（槓桿只是抽樣維度，不會讓數量膨脹）。
- **防過度擬合**：預設前 70% 訓練、後 30% 樣本外（可在步驟 1 改成 50/50、60/40、80/20）。候選與冠軍**只**用訓練期選；樣本外僅在冠軍確定後驗收（有單元測試證明改動樣本外資料不會改變冠軍）。
- **三位冠軍**：最高勝率、最高淨報酬、最穩定（最低交易數預設 20；訓練期曾清算者不得當選）。
- **新手 UX**：所有名詞旁有 ⓘ（滑鼠移上去／點擊，手機點擊），白話說明並附常見誤解。

## 回測假設（重要）

| 項目 | 規則 |
|---|---|
| 進場 | 第 s 根收盤後訊號成立 → 第 s+1 根**開盤價**成交（加不利滑價與手續費） |
| 同根 K 線同時碰到停損與停利 | 一律先停損（保守） |
| 開盤跳空越過停損 | 以更差的開盤價成交；跳空越過停利以停利價成交 |
| 移動停損 | 先用當根最高（空單最低）更新，再檢查是否觸發（保守） |
| 清算 | 逐倉；清算價 `(q·p − 保證金)/(q·(1−mmr))`（空單對稱），用標記價格判斷；清算損失 = 該筆全部保證金 |
| 資金費率 | 持倉經過的每根 K 線，計入該根內所有結算（名目價值 × 標記價 × 費率）；現貨沒有 |
| 資金分配 | 初始資金平均分成 N 份，各幣種獨立資金袋與複利，淨值相加 |
| 現貨 | 僅做多、1× |
| 樣本內／外切割 | 以時間軸前 70%／後 30%；兩段各自獨立回測，區間末強制平倉，樣本外不使用切割點前的訊號進場 |
| 穩定度 | Sharpe 18、Sortino 8、PF 14、最大回撤 18、交易數 8、跨幣正報酬 8、正報酬月份 10、清算風險 16（0～100） |

> 回測不代表未來績效，本工具僅供學習研究，不是投資建議。

## 使用

```bash
npm install            # 只有開發／測試需要
npm run serve          # http://localhost:4173 （服務 public/）
npm test               # 單元測試（Node 內建 test runner）
npm run test:e2e       # Playwright（以假的 Binance 回應執行，不需連網）
npm run sync           # public/ → docs/
npm run check:sync     # 檢查 public/ 與 docs/ 是否一致
```

純靜態網站，沒有建置步驟。直接開 `public/index.html` 需透過 HTTP 伺服器（ES Module 限制）。

## 部署到 GitHub Pages

1. 修改 `public/` 後執行 `npm run sync`，把結果提交（`docs/` 是發佈資料夾，CI 與單元測試會檢查兩者一致）。
2. GitHub → Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/docs`。
   - 若選 `/ (root)`：根目錄的 `index.html` 會自動轉址到 `docs/`，同樣可用。
3. 所有資源皆為相對路徑，放在子路徑（`https://<user>.github.io/<repo>/`）即可運作。

## 專案結構

```
public/            原始碼（部署用）
  js/core/         指標、型態、條件、引擎、指標計算、搜尋（純函式，可在 Node 測試）
  js/data/         Binance API + IndexedDB 快取
  js/worker/       Web Worker（大量運算，可取消）
  js/ui/           介面、圖表、名詞說明
  vendor/          TradingView Lightweight Charts（Apache-2.0）
docs/              public/ 的完整複本（GitHub Pages）
tests/unit         單元測試    tests/e2e  Playwright
```

## 注意事項

（與網站內「新手篇 → 注意事項」同一份內容，來源：`public/js/ui/notes.js`）

### 回測的本質限制
- 回測只是用過去的資料模擬，不代表未來，也不是投資建議；加密貨幣波動極大，槓桿可能讓你損失全部本金。
- 實盤會比回測差：成交量不足時滑價變大、網路與 API 延遲、情緒影響執行。本平台滑價是固定比例，清算價是簡化估算（未含分級保證金與清算手續費）。上線前請先用負擔得起的小額資金驗證。
- 同一根 K 線內「先停損還是先停利」無法得知，一律保守假設（先停損）。
- 只掃得到目前仍在交易的標的（已下架的幣、已下市的股看不到），結果偏樂觀（倖存者偏差）。
- 用今天的漲幅榜選幣再回測過去，是事後挑贏家，會高估績效。

### 過度擬合
- 搜尋的組合越多，越容易碰巧挑到貼合過去的運氣組合；冠軍樣本外變差是常態。
- 「同時搜尋指標參數」會讓可挑的組合更多，更容易過度擬合；網路上的「標準參數」只是慣例，不是最佳解。
- 樣本外只能用來驗收，不要因為某組樣本外特別好就改選它；參數敏感度的樣本外格子也只供檢視。
- 交易次數太少（少於 20～30 筆）時結論容易只是巧合；勝率高但賺小賠大一樣會虧。
- 走動式驗證：沒有合格冠軍的折會空手；折數越多、每折訓練越短，結果越雜訊。

### 功能上的限制
- 共用資金池滿檔時略過的訊號不會補進場。
- 「非」搭配事件型條件（交叉、型態）幾乎每根都成立，通常沒有意義。
- 台股只有日線；還原股價不含現金股利；FinMind 免費額度有限。
- Binance 在部分地區（如美國）會拒絕連線（HTTP 451）。

### 儲存、匯出與比較
- 「我的回測」只存在這台裝置的瀏覽器（localStorage），清除網站資料、無痕視窗或換裝置就看不到；請用「匯出 JSON」備份。最多 30 筆，超過丟掉最舊的。
- 儲存的是設定＋績效摘要＋約 260 點的淨值曲線，不含逐筆交易（逐筆請匯出 CSV）。載入設定後需重新執行回測。
- 匯出時間一律 UTC；CSV 為 UTF-8（含 BOM）。匯入的 JSON 只被當成資料檢查，不會執行程式碼。
- 並排比較時，市場、標的、期間、訓練／樣本外比例或成本不同，數字不能直接比較（畫面會提示）。

## 已知限制

- 台股只有日線（5m/15m/1h 沒有免費且可由瀏覽器使用的來源）；只掃得到目前仍在交易的股票；還原股價相當於股利再投入、不含現金股利；FinMind 免費額度有限（可在進階設定填入免費 Token）。
- 區域限制：Binance 在部分地區（如美國）會拒絕連線（HTTP 451），此時請改用其他網路環境。
- 逐倉清算價、維持保證金率為簡化估計（未含分級保證金與清算手續費）。
- 5m／多幣種／多年資料量很大，首次下載較慢，之後會暫存在瀏覽器 IndexedDB。
- 共用資金池模式下，滿檔時被略過的訊號不會補進場；「非」用於事件型條件（例如交叉、型態）時幾乎每根都成立，通常沒有意義。
- 走動式驗證是對「整套搜尋流程」的檢驗，不是對單一策略；折數越多、每折訓練越短，結果越雜訊。
- 篩選大量組合本身就會產生「運氣好」的結果，請務必看樣本外，並理解它也不保證未來。
